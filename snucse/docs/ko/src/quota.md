# 리소스 쿼터

인스턴스 수, CPU 수, 메모리, 볼륨 수와 용량, 스냅샷, GPU 등 만들 수 있는 자원의 양은 계정마다 **리소스 쿼터**로 정해져 있습니다. 쿼터를 넘기는 요청은 거부됩니다.

- 현재 사용량과 한도는 로그인 후 첫 화면(대시보드)의 자원 카드에서 볼 수 있습니다.
- 새로 만들어진 계정의 쿼터는 모두 **0**입니다. 정식 오픈 후 쿼터 신청 절차를 안내할 예정이며, 그 전에는 <contact@bacchus.snucse.org>로 문의해 주세요.
- 쓰지 않는 인스턴스와 볼륨은 삭제해 주세요. 정지된 인스턴스도 볼륨과 쿼터를 그대로 차지합니다.

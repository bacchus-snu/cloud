# 데이터 꺼내기

GPU를 쓸 수 없을 때(GPU 쿼터 만료, 빈 GPU 없음), 인스턴스가 부팅하지 않을 때, 인스턴스를 지운 뒤 디스크의 데이터가 필요할 때 쓰는 방법입니다. 어느 방법이든 디스크를 다른 호스트로 옮겨야 하면 [같은 확인 창](instance.md#배치-확인과-디스크-이동)으로 먼저 묻고, 승인해야만 옮깁니다.

| 상황 | 방법 |
| --- | --- |
| GPU 인스턴스를 GPU 없이 켜서 데이터를 꺼내고 싶다 | [작은 CPU 오퍼링으로 바꿔 시작하기](#작은-cpu-오퍼링으로-바꿔-시작하기) |
| 부팅하지 않는 인스턴스의 데이터 디스크, 남긴 루트 디스크를 읽고 싶다 | [다른 인스턴스에 디스크 붙이기](#다른-인스턴스에-디스크-붙이기) |
| 지운 인스턴스를 남긴 루트 디스크로 다시 쓰고 싶다 | [남긴 루트 디스크로 인스턴스 만들기](#남긴-루트-디스크로-인스턴스-만들기) |
| 디스크 전체를 파일로 받고 싶다 | [볼륨 다운로드](#볼륨-다운로드) |

## 작은 CPU 오퍼링으로 바꿔 시작하기

1. 인스턴스를 정지합니다.
2. **인스턴스 확장**에서 컴퓨트 오퍼링 `cpu`를 고르고 vCPU와 메모리(예: vCPU 2개, 메모리 4 GiB)를 정합니다. 운영체제 디스크 크기는 그대로입니다. CPU 인스턴스용 vCPU·메모리 쿼터가 있어야 합니다.
3. **인스턴스 시작**을 누릅니다. 디스크가 있는 호스트에 자리가 없으면 디스크를 옮겨도 되는지 묻습니다.
4. SSH로 들어가 데이터를 받습니다(`scp`, `rsync`, [인스턴스에 접속하기](access.md)). CPU 인스턴스에는 사용 기한이 없습니다.
5. 다시 GPU로 쓰려면 정지한 뒤 **인스턴스 확장**에서 원래 GPU 오퍼링을 고릅니다. 그 종류의 GPU 쿼터가 있어야 합니다.

## 다른 인스턴스에 디스크 붙이기

1. 붙일 디스크를 준비합니다.
   - 데이터 디스크: 원래 인스턴스를 정지하고 볼륨 목록에서 그 볼륨의 **디스크 분리**를 누릅니다.
   - 운영체제 디스크: 원래 인스턴스를 **루트 디스크 남기기**를 켠 채 삭제하면 `ROOT-<번호>` 볼륨으로 남습니다([인스턴스 삭제와 루트 디스크](instance.md#인스턴스-삭제와-루트-디스크)).
2. 데이터를 꺼낼 작은 CPU 인스턴스를 만듭니다(예: vCPU 2개, 메모리 2 GiB). 이미 있는 인스턴스를 써도 됩니다.
3. 볼륨 목록에서 그 디스크를 고르고 **디스크 연결**에서 그 인스턴스를 고릅니다.
   - 인스턴스가 정지돼 있으면 연결만 기록합니다. 디스크가 다른 호스트에 있으면 인스턴스를 시작할 때 옮겨도 되는지 묻습니다.
   - 인스턴스가 실행 중이고 디스크가 다른 호스트에 있으면, 연결할 때 디스크를 인스턴스가 있는 호스트로 옮겨도 되는지 묻습니다.
4. 인스턴스 안에서 파일시스템이 있는 파티션을 찾아 읽기 전용으로 마운트합니다.

   ```console
   $ lsblk -f
   $ sudo mount -o ro /dev/vdb1 /mnt
   ```

   같은 템플릿으로 만든 XFS 디스크(Rocky Linux, AlmaLinux)는 파일시스템 UUID가 같아서 `-o ro,nouuid`를 붙여야 마운트됩니다.
5. 다 쓰면 `sudo umount /mnt` 후 **디스크 분리**를 누릅니다. 같은 템플릿의 루트 디스크를 붙인 채 재시작하면 엉뚱한 디스크로 부팅될 수 있으니 붙여 둔 채로 두지 마세요.

볼륨 스냅샷이 있다면 **스토리지 → 스냅샷**에서 그 스냅샷으로 **볼륨 생성**을 한 뒤 같은 방법으로 붙일 수도 있습니다.

## 남긴 루트 디스크로 인스턴스 만들기

인스턴스를 **루트 디스크 남기기**를 켠 채 삭제했다면 그 루트 디스크로 인스턴스를 다시 만들 수 있습니다. 원래와 다른 컴퓨트 오퍼링(예: GPU 오퍼링 대신 `cpu`)을 골라도 됩니다.

1. 볼륨 목록에서 그 볼륨(`ROOT-<번호>`)을 고르고 **이 볼륨으로 인스턴스 만들기**를 누릅니다.
2. 만들기 화면이 그 볼륨을 고른 채로 열립니다. 컴퓨트 오퍼링과 이름을 고릅니다. 디스크 크기는 볼륨 그대로입니다.
3. 그 볼륨이 있는 호스트에 자리가 없으면 디스크를 옮겨도 되는지 묻습니다.

만든 뒤에는 그 볼륨이 새 인스턴스의 운영체제 디스크가 됩니다.

## 볼륨 다운로드

1. 디스크가 인스턴스에서 분리돼 있거나, 붙어 있는 인스턴스가 정지돼 있어야 합니다.
2. 볼륨 목록에서 그 볼륨을 고르고 **볼륨 다운로드**를 누릅니다. 준비가 끝나면 다운로드 링크가 나옵니다.
3. 받는 파일은 디스크 전체의 이미지(QCOW2)입니다. `qemu-img convert -O raw <파일> disk.img`로 바꾸거나 `qemu-nbd`, `guestmount`로 열어 파일을 꺼냅니다.

- 디스크 전체를 복사하는 것이라 크기에 따라 시간이 걸립니다.
- 다운로드용 사본은 남아 있는 동안 스토리지 쿼터를 차지하고, 링크는 몇 시간 뒤 사라집니다. 링크가 나오면 바로 받으세요.
- 링크가 열리지 않으면 <contact@bacchus.snucse.org>로 알려 주세요.

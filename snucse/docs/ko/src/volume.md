# 볼륨과 스냅샷

인스턴스의 디스크는 **볼륨**이고, 어느 한 시점의 볼륨을 통째로 복사해 둔 것이 **스냅샷**입니다. 둘은 저장되는 곳도, 쓰임도 다릅니다.

| | 볼륨 | 스냅샷 |
| --- | --- | --- |
| 무엇인가 | 인스턴스가 읽고 쓰는 디스크. 운영체제 디스크(루트)와 데이터 디스크가 있습니다 | 어느 한 시점의 볼륨 전체를 복사해 둔 것 |
| 어디에 있나 | 인스턴스가 실행되는 호스트의 로컬 스토리지 | 호스트와 따로 있는 2차 스토리지 |
| 인스턴스에 붙이기 | 붙일 수 있습니다 | 직접 붙일 수 없습니다. 볼륨으로 만든 뒤에 붙입니다 |
| 호스트·인스턴스·볼륨이 없어지면 | 그 호스트에 문제가 생기면 함께 영향을 받고, 볼륨을 지우면 사라집니다 | 그대로 남습니다 |
| 쿼터 | 스토리지 쿼터 | 같은 스토리지 쿼터 |

- 볼륨과 스냅샷은 하나의 스토리지 쿼터를 함께 씁니다([리소스 쿼터](quota.md)). 스냅샷은 만들 때마다 볼륨 전체를 복사하므로 쌓이면 쿼터를 많이 차지합니다. 개수 제한은 없습니다.
- 인스턴스, 볼륨, 스냅샷을 지우는 일은 모두 바로 이루어지고 되돌릴 수 없습니다. 휴지통은 없습니다. 지울 때마다 확인 창이 이름(여러 개를 한꺼번에 지울 때는 개수)을 입력하라고 묻습니다.

## 볼륨

왼쪽 메뉴의 **스토리지 → 볼륨**에서 내 볼륨을 봅니다. 인스턴스를 만들 때 정한 운영체제 디스크와 데이터 디스크, 인스턴스를 지우면서 남긴 루트 디스크가 모두 여기에 있습니다. 볼륨 화면에는 상태에 맞는 버튼만 보입니다.

| 하려는 일 | 버튼 |
| --- | --- |
| 새 데이터 디스크 만들기 | 목록 위의 **볼륨 생성** |
| 인스턴스에 붙이기, 떼기 | **디스크 연결**, **디스크 분리** |
| 키우기 | **볼륨 크기 변경**([디스크 늘리기](instance.md#디스크-늘리기)) |
| 이름 바꾸기 | **이름 바꾸기**([이름](#이름)) |
| 스냅샷 만들기 | **스냅샷 생성**, **정기 스냅샷**([스냅샷](#스냅샷)) |
| 이 디스크로 새 인스턴스 만들기 | **이 볼륨으로 인스턴스 만들기**([내 디스크로 인스턴스 만들기](#내-디스크로-인스턴스-만들기)) |
| 파일로 받기 | **볼륨 다운로드**([데이터 꺼내기](rescue.md#볼륨-다운로드)) |
| 지우기 | **볼륨 파기**(인스턴스에 한 번도 붙이지 않고 만들기만 한 볼륨에는 **볼륨 삭제**가 대신 보입니다) |

### 볼륨 지우기

인스턴스에 붙어 있지 않은 볼륨만 지울 수 있습니다. 붙어 있으면 먼저 **디스크 분리**를 하세요.

**볼륨 파기**(또는 **볼륨 삭제**)를 누르면 "삭제하려면 리소스 이름을 정확히 입력하십시오"라는 안내와 볼륨 이름이 나옵니다. 그 이름을 입력해야 **확인**을 누를 수 있습니다. 볼륨은 바로 지워지고 되돌릴 수 없습니다. 그 볼륨으로 만든 스냅샷은 지워지지 않고 그대로 남습니다.

## 스냅샷

**스토리지 → 스냅샷**에서 내 스냅샷을 봅니다. 스냅샷은 만드는 데 시간이 걸리고, 상태가 **백업됨**이 되어야 새 볼륨 만들기, 되돌리기, 새 인스턴스 만들기를 할 수 있습니다.

### 만들기

볼륨 화면에서 **스냅샷 생성**을 누릅니다. 이름은 비워도 됩니다. 비우면 `<볼륨 이름>-snapshot-<번호>`가 붙고, 번호는 내 계정에서 그 이름으로 지금까지 쓴 가장 큰 번호의 다음 수입니다. 처음은 0이고(`test-ROOT-snapshot-0`, `test-ROOT-snapshot-1`, …), 지운 스냅샷의 번호도, 재설치하거나 같은 이름으로 다시 만든 인스턴스의 디스크도 번호를 이어 가므로 번호가 클수록 나중에 만든 스냅샷입니다.

운영체제 디스크의 스냅샷이 만들어지는 중에는 그 인스턴스를 지울 수 없습니다. 상태가 **백업됨**이 된 뒤에 지우세요.

### 정기 스냅샷

볼륨 화면의 **정기 스냅샷**을 열고 **스케줄** 탭에서 **간격 유형**(매시간·매일·매주·매월), 시간, 시간대, **유지**할 스냅샷 개수를 정한 뒤 **확인**을 누르면 정해진 때마다 스냅샷이 만들어집니다. 개수가 **유지**를 넘으면 가장 오래된 스냅샷부터 지워집니다. 이름은 정할 수 없고 위의 기본 이름이 붙습니다. 만든 스케줄은 같은 창의 **정기 스냅샷** 탭에서 보고 지웁니다. 쌓이는 스냅샷은 모두 쿼터를 차지합니다.

### 스냅샷에서 되살리기

스냅샷을 고르면 다음 버튼이 있습니다.

| 하려는 일 | 버튼 |
| --- | --- |
| 스냅샷 내용으로 새 볼륨 만들기 | **볼륨 생성** |
| 볼륨을 스냅샷을 만든 때의 내용으로 되돌리기 | **스냅샷 복원** |
| 운영체제 디스크의 스냅샷으로 새 인스턴스 만들기 | **스냅샷으로 인스턴스 만들기** |

- **볼륨 생성**은 스냅샷에서 새 볼륨을 만듭니다. 이름을 비우면 무작위 이름이 붙으니 알아볼 수 있는 이름을 주세요. 만든 볼륨은 데이터 디스크처럼 인스턴스에 붙여 파일을 꺼내거나([데이터 꺼내기](rescue.md#다른-인스턴스에-디스크-붙이기)), 운영체제 디스크의 스냅샷에서 만든 볼륨이면 새 인스턴스를 만드는 데 씁니다.
- **스냅샷 복원**은 스냅샷에 따라 보이지 않을 수 있습니다. 쓰면 볼륨이 스냅샷 시점의 내용으로 돌아가고, 그 뒤에 쓴 내용은 사라집니다. 보이지 않으면 **볼륨 생성**을 쓰세요.
- 새 인스턴스를 만드는 방법은 [내 디스크로 인스턴스 만들기](#내-디스크로-인스턴스-만들기)에 있습니다.

### 스냅샷 지우기

스냅샷 화면에서 **스냅샷 삭제**를 누르면 스냅샷이 완전히 삭제되며 복구할 수 없다는 안내가 나옵니다. 스냅샷 이름을 입력해야 **확인**을 누를 수 있고, 목록에서 여러 개를 골라 한꺼번에 지울 때는 이름 대신 고른 개수를 입력합니다. 스냅샷은 하나하나가 통째 복사본이라 하나를 지워도 다른 스냅샷에는 영향이 없고, 지운 만큼 스토리지 쿼터가 돌아옵니다.

## 내 디스크로 인스턴스 만들기

템플릿 대신 내 디스크로 인스턴스를 만들 수 있습니다. 운영체제가 들어 있는 디스크여야 하므로, 데이터 디스크는 인스턴스를 부팅시키지 못합니다.

| 출발점 | 조건 | 만드는 곳 |
| --- | --- | --- |
| 볼륨 | 인스턴스에 붙어 있지 않고 템플릿에서 만든 볼륨: 인스턴스를 지우며 남긴 루트 디스크, 또는 운영체제 디스크의 스냅샷으로 만든 볼륨 | 볼륨 화면의 **이 볼륨으로 인스턴스 만들기**, 또는 인스턴스 만들기의 **이미지** 단계에서 **유형**을 **볼륨**으로 |
| 스냅샷 | 운영체제 디스크의 스냅샷(상태 **백업됨**) | 스냅샷 화면의 **스냅샷으로 인스턴스 만들기**, 또는 인스턴스 만들기의 **이미지** 단계에서 **유형**을 **스냅샷**으로 |

두 경우 모두 운영체제 디스크 크기는 따로 정하지 않고, 컴퓨트 오퍼링과 이름은 새 인스턴스처럼 고릅니다. 원래와 다른 오퍼링(예: GPU 대신 `cpu`)도 됩니다.

- **볼륨으로 만들면** 그 볼륨이 새 인스턴스의 운영체제 디스크가 됩니다. 그 볼륨이 있는 호스트에 자리가 없으면 디스크를 다른 호스트로 옮겨도 되는지 묻습니다([배치 확인과 디스크 이동](instance.md#배치-확인과-디스크-이동)).
- **스냅샷으로 만들면** 스냅샷을 복사해 새 운영체제 디스크를 만듭니다. 템플릿으로 만들 때처럼 자리가 있는 호스트에서 만들어져서 옮길 디스크가 없고, 스냅샷은 그대로 남습니다.

## 이름

볼륨과 스냅샷의 이름은 영문 대소문자, 숫자, 마침표(`.`), 밑줄(`_`), 하이픈(`-`)으로 64자까지 쓸 수 있습니다. 이름이 겹쳐도 됩니다. 볼륨 화면과 스냅샷 화면의 **이름 바꾸기**로 바꿉니다. 인스턴스에 붙어 있는 볼륨도 바꿀 수 있습니다.

인스턴스를 만들면 운영체제 디스크는 `<인스턴스 이름>-ROOT`라는 볼륨으로 만들어지고, 인스턴스 이름을 바꾸면 이 볼륨 이름도 따라 바뀝니다([이름 바꾸기](instance.md#이름-바꾸기)). 인스턴스 이름 규칙은 [인스턴스 이름](instance.md#인스턴스-이름)에 따로 있습니다.
